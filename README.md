# MiraBox Controller

A React and Electron desktop application for managing the **MiraBox HSV 293S Stream Deck**.

## Overview

MiraBox Controller is a powerful software solution that enables users to fully customize and control their MiraBox HSV 293S Stream Deck. This application provides an intuitive interface for managing all aspects of your stream deck configuration.

## Features

- **Upload Custom Images**: Add images (JPG, JPEG, GIF, and more) to each stream deck key with a simple drag-and-drop interface
- **Assign Key Functions**: Bind custom functions and commands to individual keys
- **Real-time System Information**: Display live computer information directly on stream deck keys
- **Cross-platform**: Built with Electron for Windows, macOS, and Linux support

## Tech Stack

- **Frontend**: React with TypeScript
- **Desktop Framework**: Electron
- **Build Tool**: Vite

## References

This project utilizes the [mirabox-streamdeck-node](https://github.com/mirabox/mirabox-streamdeck-node) repository as a reference implementation for stream deck integration and protocol implementation.

## Installation

To get started with this project:

```bash
npm install
```

## Development

To run the development server:

```bash
npm run dev
```

## Build

To build the application for production:

```bash
npm run build
```
